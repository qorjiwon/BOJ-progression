# BOJ Progression

백준 온라인 저지 워크북 진행 상황 추적 및 제출 편의 기능 크롬 확장 프로그램

## 기능

### 1. 워크북 진행률 자동 추적
- 백준 워크북 목록 페이지(`/workbook/top`)에서 각 워크북의 진행률을 자동으로 크롤링
- 워크북 상세 페이지 방문 시 해결한 문제 수와 총 문제 수를 자동으로 수집
- 워크북 목록 페이지의 progress-bar에 해결한 문제 수와 진행률을 숫자로 표시

### 2. 제출 페이지 기본 언어 자동 선택
- 제출 페이지(`/submit/숫자`)에서 설정한 기본 언어를 자동으로 선택
- 확장 프로그램 설정에서 원하는 언어를 선택하여 저장 가능

## 동작 방식

### 워크북 진행률 추적
1. 워크북 상세 페이지(`/workbook/view/숫자`) 방문 시 문제 목록과 해결 상태를 자동 크롤링
2. 해결한 문제 수(`solvedProblems`)와 총 문제 수(`totalProblems`)를 계산하여 진행률(`progress`) 저장
3. 워크북 목록 페이지 방문 시 저장된 데이터를 읽어 progress-bar의 width와 텍스트를 업데이트

### 제출 페이지 기본 언어 선택
1. 확장 프로그램 설정에서 기본 언어 선택 및 저장
2. 제출 페이지 방문 시 저장된 언어 값으로 `<select id="language">` 요소 자동 선택
3. jQuery chosen 라이브러리가 있으면 chosen을 통해 업데이트, 없으면 직접 DOM 조작

## 설치 방법

1. Chrome 브라우저에서 `chrome://extensions/` 접속
2. 우측 상단의 "개발자 모드" 토글 활성화
3. "압축해제된 확장 프로그램을 로드합니다" 버튼 클릭
4. 이 프로젝트 폴더(`BOJ-progression`) 선택

## 사용 방법

### 워크북 진행률 확인
1. 백준 워크북 상세 페이지(`/workbook/view/숫자`) 방문
2. 자동으로 문제 목록과 해결 상태가 크롤링되어 저장됨
3. 워크북 목록 페이지(`/workbook/top`)에서 각 워크북의 progress-bar에 진행률 확인

### 기본 언어 설정
1. 확장 프로그램 팝업 열기
2. "설정" 탭 클릭
3. 원하는 기본 언어 선택 후 "저장" 버튼 클릭
4. 제출 페이지 방문 시 자동으로 선택된 언어로 설정됨

## 파일 구조

```
BOJ-progression/
├── manifest.json      # 확장 프로그램 설정
├── popup.html         # 팝업 UI
├── popup.js           # 팝업 로직
├── popup.css          # 팝업 스타일
├── content.js         # 백준 사이트 크롤링 및 DOM 조작 스크립트
├── content.css        # 백준 사이트 스타일
├── background.js      # 백그라운드 서비스 워커 (데이터 저장)
└── icons/             # 아이콘 파일들
```

## 개발

이 확장 프로그램은 Manifest V3를 사용합니다.
